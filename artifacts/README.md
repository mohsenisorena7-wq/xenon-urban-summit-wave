نسخه کامل با تمام قابلیت‌ها

## قابلیت‌ها

✅ تولید کپشن اینستاگرام  
✅ تولید پست لینکدین  
✅ توضیح پروژه (Portfolio)  
✅ ایده پست و محتوای آموزشی  
✅ پرامپت حرفه‌ای برای هوش مصنوعی (Grok / ChatGPT / Claude)  
✅ هشتگ‌های تخصصی معماری  
✅ متن تبلیغاتی خدمات  
✅ داستان‌گویی پروژه (Storytelling)  
✅ **پرامپت تولید تصویر** (برای Midjourney / Flux / Grok Imagine)  
✅ **تقویم محتوایی ۳۰ روزه**  
✅ **ذخیره محتوا در فایل**  
✅ **نسخه وب با Streamlit**  
✅ تولید بسته کامل محتوا با یک کلیک  

---

## ۱. نسخه خط فرمان (CLI)

```bash
python3 architecture_ai_content.py
```

### منوی برنامه:
1. کپشن اینستاگرام
2. پست لینکدین
3. توضیح پروژه
4. ایده پست آموزشی
5. پرامپت حرفه‌ای AI
6. هشتگ‌ها
7. متن تبلیغاتی
8. داستان پروژه
9. پرامپت تولید تصویر
10. تقویم محتوایی ماهانه
11. ذخیره همه محتواهای اخیر

محتواها در پوشه `generated_content` ذخیره می‌شوند.

---

## ۲. نسخه وب (پیشنهادی)

```bash
streamlit run architecture_web_app.py
```

سپس مرورگر به آدرس `http://localhost:8501` باز می‌شود.

### تب‌های نسخه وب:
- **تولید محتوا**: کپشن، لینکدین، توضیح پروژه، ایده، داستان
- **پرامپت تصویر**: پرامپت‌های قوی برای تولید رندر و تصویر
- **تقویم ماهانه**: برنامه محتوایی ۳۰ روزه
- **پرامپت AI**: پرامپت آماده برای چت‌بات‌ها
- **هشتگ و تبلیغ**: هشتگ + متن تبلیغاتی
- **بسته کامل**: تولید و دانلود همه محتواها یکجا
